A. Profil Saya

Saya merupakan mahasiswa aktif Universitas Dian Nuswantoro dengan Program Studi Sistem Informasi, Fakultas Ilmu Komputer. Saya memilih untuk mengambil program studi sistem informasi dikarenakan saya tertarik dengan perkembangan teknologi yang kian berkembang pesat. Selain itu saya juga tertatik dengan managemant-managemant suatu sistem didalam proses bisnis yang akan sangat membantu kebutuhan manusia. disisi lain, kreatif dan berorientasi dengan pengalaman dalam menghasilkan Desain Antarmuka dan Graphic Design senantiasa antusias mengeksplorasi antara teknologi dan estetika visual menjadi minat bakat saya sampai sekarang. Berfokus pada penciptaan pengalaman digital yang menarik, inovatif, dan fungsional, serta dapat berkolaborasi yang baik dalam bekerja bersama tim guna memastikan setiap proses desain berjalan selaras dengan tujuan yang telah ditetapkan.

Halaman web ini dibuat menggunakan HTML5 murni tanpa menggunakan CSS untuk memenuhi instruksi pembuatan struktur dasar web. Dalam pembuatan halaman ini, saya menggunakan berbagai tag HTML untuk menyusun struktur dan menampilkan informasi. Saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan halaman ini menjadi salah satu latihan untuk memahami dasar-dasar pengembangan web. Dengan latihan ini, saya berharap dapat memahami HTML dengan lebih baik dan mampu menggunakannya dalam membuat halaman web yang lebih kompleks.
